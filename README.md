# 👀 GitHub Profile Views Counter

Add a simple profile view counter to your GitHub profile in just a few steps!

## 🚀 How to Add It

### Step 1 — Create Your GitHub Profile Repository

Go to [GitHub](https://github.com/) and create a new repository.

<img width="1919" height="1085" alt="image" src="https://github.com/user-attachments/assets/967522ad-6fbe-4f42-baa5-1e4ae29dc3bb" />

<img width="589" height="331" alt="image" src="https://github.com/user-attachments/assets/57b68e12-0996-42cd-894d-3c97d80dfcc9" />

**Important:** The repository name must be exactly the same as your GitHub username.

<img width="1919" height="1079" alt="image" src="https://github.com/user-attachments/assets/20d0eaa3-011a-47a6-9a46-6c05fecedd7a" />


For example:

```text
Username: JohnDoe
Repository name: JohnDoe
```

Make sure the repository is **Public** and initialize it with a `README.md` file.

<img width="763" height="842" alt="image" src="https://github.com/user-attachments/assets/a202374a-6277-4eaa-9553-747e055b153f" />


---

### Step 2 — Open Your `README.md`

Open the `README.md` file in your profile repository.

Click the **✏️ Edit** button.

<img width="1915" height="1079" alt="image" src="https://github.com/user-attachments/assets/6ff8574b-334e-45db-aa3f-242fce0c6cac" />


---

### Step 3 — Add the Profile View Counter

Add the following Markdown code to your `README.md`:

```md
![Profile views](https://komarev.com/ghpvc/?username=YOUR_USERNAME)
```

Replace `YOUR_USERNAME` with your GitHub username.

<img width="1051" height="287" alt="image" src="https://github.com/user-attachments/assets/f2a36d91-bee6-4298-a2ab-407f1a2da9c8" />


### Example

If your GitHub username is `JohnDoe`, use:

```md
![Profile views](https://komarev.com/ghpvc/?username=JohnDoe)
```

---

Scroll down and click:

**Commit changes**

## 🎨 Customize Your Counter

You can also customize the counter.

### Change the Color

You can add a color using the `color` parameter:

```md
![Profile views](https://komarev.com/ghpvc/?username=YOUR_USERNAME&color=blue)
```

<img width="639" height="80" alt="image" src="https://github.com/user-attachments/assets/5a0aac95-8784-45a8-8895-df07ec23061a" />

<img width="1551" height="255" alt="image" src="https://github.com/user-attachments/assets/cf9c22cb-9cd6-4078-b1e7-f41c5b8d793f" />



For example:

```md
![Profile views](https://komarev.com/ghpvc/?username=JohnDoe&color=blue)
```

You can use colors such as:

```text
red
green
blue
orange
pink
purple
grey
```

---

## 🔢 Show a Custom Label

You can change the text displayed next to the counter:

```md
![Profile views](https://komarev.com/ghpvc/?username=YOUR_USERNAME&label=PROFILE+VIEWS)
```

Example:

```md
![Profile views](https://komarev.com/ghpvc/?username=JohnDoe&label=PROFILE+VIEWS)
```

---

## 📌 Full Example

You can put the counter anywhere in your GitHub profile README:

```md
# Hi, I'm JohnDoe 👋

I'm a developer interested in web development and programming.

![Profile views](https://komarev.com/ghpvc/?username=JohnDoe&color=blue&label=PROFILE+VIEWS)

## About Me

- 💻 Developer
- 🚀 Building projects
- 📚 Always learning
```

---

## ⚠️ Important

The counter does **not** represent the exact number of unique people who visited your profile.

It counts requests to the profile-view counter image, so the number can be affected by caching, repeated visits, and other technical factors.

Think of it as a **profile view counter**, not an exact unique visitor statistic.
